# Ask, Assist, Learn

Thesis pitch page: human-in-the-loop learning for robot arms and humanoids in manufacturing.

- `index.html`: the whole site in one file (pitch, fleet console, 3D AR operator view)
- The 3D view loads three.js r128 from cdnjs; fonts load from Google Fonts
- The simulation is scripted for illustration, not physics

Live site: GitHub Pages from `main` / root.
